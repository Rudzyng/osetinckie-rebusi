**Описание идеи**

Цель: создать отдельную страницу на сайте [https://рудзынг.рф](https://xn--c1abjyms2d.xn--p1ai/) .

На которой будет игра “Осетинские ребусы”.На ней можно будет решать ребусы, а также создавать свои.\
Задачи:

1\.     Сделать frontend для самой игры и режима создания своих ребусов.

В основном окне можно будет выбрать тему ребуса, и сам ребус. А также пользователь будет вписывать осетинское слово сверху, исходя от условий задачи, а ниже его перевод на русский.

2\.     Привязать к frontend код

3\.     Написать алгоритм, в котором будут  выдаваться задачи в зависимости от, выбранной темы, а также проверяться ответы игрока.

4\.     Добавить функцию для создания собственного ребуса

### **Подробное описание страниц**

1. ### Главная страница из нее можно перейти в свой профиль или приступить к решению различных ребусов, выбирая тему.
2. ### Страница с ребусом представляет собой ребус, в котором над каждой буквой основного слова будет картинка, тем самым образуя ячейку с буквой и еще картинкой. При нажатие на одну из незаполненных мы переходим на подстраницу. После заполнения ребуса снизу появиться еще одна строк, в которой нужно будет записать слово на русском. После зачисляется 1 балл в портале Рудзынг, \+1 решенный ребус в нашей игре и \+n слов(зависит от кол-во записанных слов для решения ребуса).
3. ### Подстраница представляет собой ячейку, у которой картинка стала больше и теперь нужно вести значение с картинки в поле ниже. При правильном ответе первая буква этого слова переноситься в соответствующую ячейку в основном ребусе. Итог заполнена 1 буква и \+1 слово в статистике.
